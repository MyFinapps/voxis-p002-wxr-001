# HTTPS hosting for Quest Browser

The Quest Browser must receive this prototype from a secure HTTPS origin for immersive WebXR.

Good static-host choices include GitHub Pages, Netlify, and Cloudflare Pages. Upload the **contents** of this folder without changing the relative paths, then open the HTTPS site URL in Quest Browser and choose **Enter VR**.

The prototype has no server-side code and sends no research data anywhere. The two folio PNGs and all application logic are served as static files.
